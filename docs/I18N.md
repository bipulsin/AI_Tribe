# UI internationalization (EN / FR)

Display-only language toggle for the main AI Tribe UI. Does **not** translate chat
NLU, ML output, catalogue data, or claim/vehicle field values.

## Decisions (this phase)

| Topic | Choice |
| --- | --- |
| **Scope** | Login, claims (Enterprise), assessment, estimate, chat **chrome**, profile & settings panels, help modal |
| **Out of scope** | Admin panel, Usability Report, lab VMMR labeling, API Marketplace page (menu link stays English) |
| **Chat NLU** | Conversation and suggestion chips stay **English**; UI note under composer when FR is active |
| **Persistence** | Cookie `atr_lang` (`en` default, `fr` supported). No `users.preferred_language` column yet |
| **Detection** | Explicit toggle only — never `Accept-Language` |

## Files

| Path | Role |
| --- | --- |
| `backend/app/i18n/en.json` | Source-of-truth UI strings |
| `backend/app/i18n/fr.json` | Reviewed French catalog |
| `backend/app/i18n/catalog.py` | Load, `translate()`, cookie lang context |
| `backend/app/core/templates.py` | Shared Jinja env with `t()` / `get_lang()` |
| `backend/app/api/routes_i18n.py` | `GET /lang/{code}?next=` + smoke API |
| `frontend/templates/partials/lang_toggle.html` | Top-right EN / FR control |
| `frontend/static/js/i18n.js` | `atrT()` for Alpine/HTMX scripts |

## Usage in templates

```jinja
{{ t('claims.title') }}
{{ t('claims.upload_limits', max_images=10, max_mb=25) }}
<html lang="{{ get_lang() }}">
```

Missing keys fall back to English, then to the key name (never blank).

## Toggle

Fixed top-right on login and all pages using `base.html`. Sets cookie and reloads
the same URL (form state is preserved on GET pages; in-progress uploads remain in
browser memory until refresh).

Smoke check:

```bash
curl -s https://tribe.tradentical.com/api/i18n/smoke
curl -s -b 'atr_lang=fr' https://tribe.tradentical.com/api/i18n/smoke
```

## French terminology notes

Insurance-specific labels flagged for review with domain experts:

- **Claim** → *Sinistre* (not *réclamation* dossier)
- **Surveyor** → *Expert* (sinistre / expertise)
- **Estimate** → *Devis d'expertise*
- **Garage** → *Garage* / *garage réparateur* (context-dependent)

VMMR, DeepFake, API Marketplace product names kept as-is.
